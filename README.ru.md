AutoScribe — настольное приложение, которое управляет официальным **Windscribe CLI**. В версии **1.7.2** добавлены:

- **ИИ-адаптивное обучение (DPI Feedback)** — встроенный движок без внешних зависимостей (`ai_engine.py`) с профилированием сети (`NetworkProfiler`), проверкой портов (`SocketProber`), классификацией сбоев (`FailureClassifier`) и планировщиком Thompson Sampling Bandit.
- **ИИ-автопилот (AI Auto-Pilot)** — автоматический подбор стратегии обхода блокировок и приоритета протоколов/портов.
- **Проверка стабильности Anti-DPI и мини-тест скорости** — многоэтапная проверка туннеля на отложенные разрывы DPI и тест загрузки 150 КБ.
- **Сторож авто-переключения (Auto-Failover Watchdog)** — мониторинг активного VPN каждые 25 секунд с авто-ротацией IP или переключением на резервный маршрут.
- **Снимок диагностики для ИИ** — генерация структурированного отчёта для ChatGPT/Gemini/Claude.
- **Полный набор функций v1.5.0+** — выбор конкретных узлов, фильтр `[FREE]`, сохранение фаервола, HTTP-проверка, вкладка «Диагностика» и экспорт в CSV.

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

На Windows можно также запустить `run_autoscribe.bat` или собрать `.exe` через `build_standalone_exe.bat`.
